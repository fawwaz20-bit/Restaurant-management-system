# 🍽️ Restaurant Management System

A console-based Restaurant Management System developed in Java using Object-Oriented Programming concepts. This application allows customers to browse the menu, place orders, track order status, and generate bills, while administrators can manage menu items, customer orders, and sales reports.

## 📌 Features

### 👤 Client
- Login
- View restaurant menu by category
- Place multiple food orders
- Track order status
- View bill

### 👨‍💼 Management (Admin)
- Secure admin login
- Add menu items
- Update menu items
- Delete menu items
- View customer orders
- Update order status
- Generate customer bills
- View sales summary

## 🍴 Menu Categories

- Veg
- Non-Veg
- Drinks
- Desserts

## 🔄 Order Status

- Placed
- Pending
- Preparing
- Completed

## 🛠️ Technologies Used
